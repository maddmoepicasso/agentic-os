# Proposal Pack Generator

## Description
Creates a polished proposal pack for selling a service, automation, agent setup, content engine, SEO package, or launch kit implementation.

## When to Use
- User needs a proposal for a prospect
- User wants to package an automation or launch kit as a paid service
- User needs scope, deliverables, timeline, and pricing language

## Input
- Client type
- Client pain
- Desired outcome
- Offer or service
- Deliverables
- Timeline
- Pricing if known

## Process
1. Summarize the client's current problem.
2. Define the desired outcome.
3. Package the service into 3-7 deliverables.
4. Add timeline and implementation phases.
5. Add responsibilities: user, client, AI/Agent OS.
6. Add pricing section or placeholder.
7. Add next steps and acceptance language.
8. Include risks, assumptions, and exclusions.

## Output
- Client proposal draft
- Scope of work
- Timeline
- Next-step message
