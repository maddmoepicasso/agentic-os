## Process
1. Pick one local-intent keyword from the Picassomoes keyword clusters.
2. Write a helpful Reddit-ready post using the keyword as a natural question or local guide title.
3. Start with the direct answer, then add practical details, examples, and decision criteria.
4. Include one soft funnel link near the end only when it genuinely helps the reader.
5. Create a website/blog reuse version with intro, H2s, local context, CTA, and internal link suggestions.
6. Create Instagram, YouTube Shorts, LinkedIn, and X reuse copy.
7. Add safety language for aftercare, healing, pain, infection concerns, pricing, and medical topics.
8. Mark output as draft-only unless publishing has truly happened.
9. Save learnings or reusable proof to Obsidian when requested or configured.

## Safety Rules
- Do not overpromise medical results, healing timelines, pain levels, or exact pricing.
- Encourage clients to follow their artist's instructions.
- For unusual redness, heat, swelling, discharge, fever, allergic reactions, or severe pain, suggest medical care.
- For pricing, say final pricing depends on size, detail, placement, style, and drawing time unless the user provides an official price.
- Avoid spam, fake review language, copied competitor content, and keyword stuffing.
