# Social Post Scheduler

## Description
Builds a simple posting plan from a topic, offer, launch kit, or business goal. It creates daily post ideas, hooks, captions, and calls to action.

## When to Use
- User wants a weekly or monthly content calendar
- User has a launch kit and needs promotional posts
- User wants more consistent social output

## Input
- Topic or offer
- Platform(s)
- Posting frequency
- Audience
- Voice/tone

## Process
1. Define the campaign goal.
2. Choose content pillars.
3. Generate a schedule.
4. Write hooks and captions.
5. Add CTA per post.
6. Mark which posts can become short videos or emails.
7. Provide a tracking checklist.

## Output
- Posting calendar
- Captions and hooks
- CTA map
- Reuse notes
