# Avatar Video Pipeline

## Description
Creates a repeatable production plan for AI avatar videos, faceless videos, short-form clips, or promo videos. It focuses on scripting and workflow orchestration rather than requiring a specific paid video tool.

## When to Use
- User wants avatar video content
- A launch kit needs a video script
- User wants faceless YouTube or short-form video assets

## Input
- Topic or offer
- Audience
- Desired video length
- Platform
- Voice/tone
- Tool constraints

## Process
1. Define the video promise and audience.
2. Write a hook.
3. Draft a tight script.
4. Add visual beats or avatar cues.
5. Add B-roll or screen capture notes.
6. Add captions and title ideas.
7. Add production checklist.
8. Add publishing checklist.

## Output
- Video script
- Shot/visual notes
- Caption/title options
- Production checklist
