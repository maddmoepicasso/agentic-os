# SEO Article Generator

## Description
Creates a complete SEO article or landing-page draft from a keyword, audience, offer, and proof assets. It is built for useful, specific content rather than generic filler.

## When to Use
- User wants an article, service page, or guide
- A keyword from the queue is ready to write
- A page needs on-page SEO improvements
- User wants an article with a real CTA and proof

## Input
- Target keyword
- Audience and search intent
- Business, product, service, or offer
- Case study, proof, story, or local details
- Internal links and desired CTA

## Process
1. Confirm search intent and page goal.
2. Create a title, meta description, URL slug, and H1.
3. Build a useful outline with H2/H3 structure.
4. Add proof sections using supplied case studies or user notes.
5. Write clear body copy with examples, caveats, and next steps.
6. Add FAQ questions that match real user concerns.
7. Add internal link recommendations and external citation placeholders.
8. Add CTA copy that fits the business goal.
9. Run a final quality check for keyword stuffing, thin claims, and missing proof.

## Output
- SEO article brief
- Draft article
- Meta title and description
- FAQ block
- Internal link plan
- CTA copy
- On-page QA notes
