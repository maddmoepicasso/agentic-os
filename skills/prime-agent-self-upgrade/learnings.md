# Prime Agent Self-Upgrade Learnings

- Start Prime Agent on low-stakes, reversible projects before allowing it near
  live business systems.
- Persist useful corrections with `/refine`, then mirror durable lessons into
  Agent OS memory or the matching skill notebook so the control plane can audit
  what is compounding.
- Weekly notebook review is mandatory because self-improvement compounds what
  works mechanically, which may not match the operator's intent.
