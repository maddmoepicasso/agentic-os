# GOLDIE Infinite Rank OS

## Description
Turns the pasted GOLDIE SEO operating system into a repeatable Angelic OS workflow. It coordinates the thinking layer, doing layer, memory layer, and publishing layer so a keyword can move from idea to draft to deployment checklist to performance review.

This skill does not promise ranking results. It creates a disciplined SEO workflow that can improve publishing quality, consistency, and follow-up.

## When to Use
- User wants to rank a page, article, service page, or case study
- User has a keyword list and needs a publishing plan
- User wants Hermes/OpenClaw/Obsidian to support SEO work
- User asks for the GOLDIE, Infinite Rank, or SEO OS flow

## Input
- Site or business name
- Niche, service, location, or offer
- Target keyword or keyword queue
- Case studies, proof, customer stories, or internal notes
- Publishing target, such as Netlify, Cloudflare, WordPress, or static files
- Indexing and measurement tools available

## Process
1. Define the goal: target keyword, audience, offer, page type, and success metric.
2. Choose the best supporting skills: keyword miner, article generator, topical map, publishing checklist, case study memory, and performance review.
3. Create a keyword-to-page plan with priority, intent, proof assets, and internal links.
4. Generate or improve the article with title, meta description, headings, FAQ, CTA, and internal link plan.
5. Run an on-page SEO review before publishing.
6. Create a publish checklist for Netlify or the current hosting setup.
7. Create an indexing follow-up task for Omega Indexer, Google Search Console, or the chosen index workflow.
8. Save the result, decisions, and lessons into the Obsidian Agentic OS folder when a vault path is configured.
9. Schedule a 7-day performance review task.

## Output
- SEO work order
- Article brief or article draft
- Publish checklist
- Indexing checklist
- Obsidian learning note
- Follow-up performance review task
