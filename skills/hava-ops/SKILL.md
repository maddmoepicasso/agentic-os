# hava-ops

## Description
Track Hava project links, website status, Cloudflare access, and next actions.

## When to Use
- Hava project tasks, links, hosting, or audits

## Input
- Project, brand, URL, folder, or task details relevant to the business/project.
- Desired output, urgency, and whether changes should be made or only audited.

## Process
1. Find the current valid Hava URLs before acting.
2. Check whether the site should be public or private.
3. Keep links, DNS, and project notes current.
4. Add unresolved items to the command center.

## Output
- Hava status, links, blockers, and next steps.

## Agent Assignment
- Primary: codex
- Fallback: opencode

## Dependencies
- Agentic OS brain, prompt library, and project-specific context.
