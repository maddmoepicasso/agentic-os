# codex-website-seo

## Description
Add practical technical SEO and content foundations to a website.

## When to Use
- Improving search visibility for a site, service business, blog, or local landing page

## Input
- Target website
- Brand, location, service area, and primary keywords

## Process
1. Back up the current site files.
2. Check canonical URLs, titles, descriptions, robots, sitemap, and social metadata.
3. Add structured data when it fits the business, such as LocalBusiness or TattooParlor.
4. Create useful guide pages around real search intent.
5. Keep claims accurate and avoid spammy or deceptive content.
6. Verify pages build and important URLs resolve.

## Output
- SEO changes list
- New/updated URLs
- Keyword/content plan

## Dependencies
- Website source or CMS access
- Brand/location details
