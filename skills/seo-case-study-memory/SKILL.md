# SEO Case Study Memory

## Description
Turns messy notes into reusable case studies, snippets, proof blocks, and Obsidian-ready markdown so SEO content can sound grounded and real.

## When to Use
- User has a result, customer story, ranking movement, or campaign note
- An article needs proof
- Weekly SEO learning should be saved
- User wants the Agent OS memory to improve future content

## Input
- Raw note, result, or story
- Client/business/site context
- Before and after details when available
- Metrics, screenshots, quotes, or caveats
- Tags or target keywords

## Process
1. Extract the situation, action, result, lesson, and reusable proof.
2. Separate verified facts from assumptions.
3. Create a concise case study note.
4. Create smaller proof snippets for future articles.
5. Add tags for business, niche, keyword, offer, and page type.
6. Suggest where the proof can be reused.
7. Save as markdown when the Obsidian folder is configured.

## Output
- Obsidian-ready case study note
- Reusable proof snippets
- Suggested article placements
- Tags and metadata
