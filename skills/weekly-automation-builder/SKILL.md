# Weekly Automation Builder

## Description
Builds one useful automation at a time. It turns a rough idea into a simple workflow, defines the trigger, action, output, and owner, then creates the files, prompts, tasks, or scripts needed to make it real.

## When to Use
- User says they want to automate something
- Weekly planning asks for one automation to build
- A repeated manual workflow is wasting time
- A launch kit needs to become an operating procedure

## Input
- Automation idea or pain point
- Current manual process
- Desired output
- Tool constraints
- Any accounts or services involved

## Process
1. Name the automation in plain language.
2. Define the trigger: time, user action, new lead, new content, new message, or manual button.
3. Define inputs and where they come from.
4. Define the steps the AI should perform.
5. Define the final output and where it should be saved.
6. Decide whether this should be a skill, prompt, Kanban checklist, script, or external workflow.
7. Build the smallest working version.
8. Test once with sample data.
9. Save instructions and next improvements.

## Output
- Automation brief
- Implementation checklist
- Local skill/prompt/task/script when appropriate
- Test result and next improvement
