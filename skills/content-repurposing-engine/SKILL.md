# Content Repurposing Engine

## Description
Converts one piece of source content into a multi-channel content pack while preserving the user's voice and offer. Useful for turning launch kits, notes, videos, or long posts into daily content.

## When to Use
- User has a video transcript, article, note, or offer and wants multiple posts
- A launch kit needs promotional content
- A business needs email/social content from one idea
- User asks for an omnipresence/content engine

## Input
- Source content
- Audience
- Offer or call to action
- Channels needed
- Tone preference

## Process
1. Extract the core promise, pain, proof, mechanism, and call to action.
2. Create a message map with 3-5 angles.
3. Generate short-form posts for chosen platforms.
4. Generate one email or newsletter.
5. Generate one short video/avatar script.
6. Generate hooks and subject lines.
7. Add a reuse calendar if requested.
8. Save outputs as markdown when the user wants a file.

## Output
- Content pack with platform-specific drafts
- Hook bank
- Email draft
- Short video script
- Optional schedule
