# SEO Topic Cluster Planner

## Description
Builds a structured SEO content map so Angelic OS can publish in clusters instead of random one-off articles.

## When to Use
- User wants a 30-day SEO roadmap
- User has a niche and needs article ideas
- User wants internal linking planned before writing
- User wants to build topical authority around a service or offer

## Input
- Main niche, product, service, or local market
- Existing pages
- Target offers
- Seed keywords
- Business priorities

## Process
1. Define the main pillar topic.
2. Break the pillar into subtopics, questions, comparisons, objections, and local variants.
3. Assign page types to each topic.
4. Recommend internal links between pillar, supporting articles, case studies, and conversion pages.
5. Create a publishing order that starts with the highest-value pages.
6. Flag proof, examples, or case studies needed for each page.
7. Create a weekly publishing calendar when requested.

## Output
- Topic cluster map
- Pillar and support page list
- Internal linking plan
- Publishing order
- Proof requirements
