# GOLDIE Infinite Rank OS

This guide has been implemented into Angelic OS as a practical SEO operating layer.

## Installed Skills

- `goldie-infinite-rank-os` runs the full loop from keyword to publish to review.
- `seo-keyword-opportunity-miner` builds a prioritized keyword queue.
- `seo-topic-cluster-planner` creates pillar/support page maps.
- `seo-article-generator` writes SEO briefs and drafts.
- `seo-case-study-memory` turns wins and notes into reusable proof assets.
- `seo-publishing-checklist` creates publish, index, and follow-up checklists.
- `seo-performance-review` reviews pages after publishing and creates next actions.

## Operating Model

- Thinking layer: Codex or Hermes plans the page and evaluates quality.
- Doing layer: Hermes/OpenClaw can run repeatable work when configured.
- Memory layer: Obsidian stores case studies, lessons, and daily notes.
- Publishing layer: Netlify, Cloudflare, or the current host publishes the page.
- Indexing layer: Google Search Console or Omega Indexer handles follow-up submission when credentials are available.

## Important Guardrail

The system supports SEO execution. It does not guarantee Google rankings. Rankings depend on competition, site authority, content quality, indexing, links, technical health, and time.

## Basic Workflow

1. Add a keyword or topic to the queue.
2. Run `seo-keyword-opportunity-miner`.
3. Run `seo-topic-cluster-planner` if the topic needs a bigger map.
4. Run `seo-article-generator`.
5. Run `seo-publishing-checklist`.
6. Publish and submit/index through the tools you have connected.
7. Run `seo-performance-review` after 7 days.
8. Save lessons into Obsidian using `seo-case-study-memory`.
