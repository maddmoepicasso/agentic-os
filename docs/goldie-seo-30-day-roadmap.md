# GOLDIE SEO 30-Day Roadmap

## Week 1: Foundation

- Confirm OpenClaw and Hermes are online.
- Confirm Obsidian Agentic OS folder exists.
- Choose one website or business to start with.
- Create the first 25-keyword queue.
- Pick the first 5 quick-win pages.

## Week 2: Content System

- Build one topic cluster.
- Create the first article brief.
- Draft and QA the first SEO article.
- Add case study proof to the article.
- Publish the first page and record the live URL.

## Week 3: Publishing and Indexing

- Create a repeatable publish checklist.
- Connect or document Netlify, Cloudflare, or the current hosting path.
- Submit the first published URL to the available indexing workflow.
- Create a 7-day review card for every new page.
- Save publish notes to Obsidian.

## Week 4: Scale and Improve

- Review the first pages using Search Console or available metrics.
- Improve titles, meta descriptions, internal links, and content depth.
- Create a second topic cluster.
- Build a weekly publishing rhythm.
- Turn the best lessons into reusable case studies and proof snippets.
