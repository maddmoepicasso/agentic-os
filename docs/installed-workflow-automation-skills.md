# Installed Workflow Automation Skills

Installed into Angelic OS on 2026-09-12.

## Starter Pack

- `automation-inbox-triage` - Sort pasted guides, links, and workflow ideas into skills, prompts, tasks, or references.
- `workflow-template-installer` - Convert reviewed external templates into Angelic OS skills, prompts, or tasks.
- `weekly-automation-builder` - Build one practical automation per week from idea to tested workflow.
- `content-repurposing-engine` - Turn one source idea into posts, emails, hooks, and short video scripts.
- `client-follow-up-automation` - Build follow-up sequences for leads, prospects, clients, and dormant opportunities.
- `proposal-pack-generator` - Create proposal packs with scope, deliverables, timeline, and next steps.
- `lead-capture-router` - Score incoming leads and recommend next actions.
- `social-post-scheduler` - Create social posting calendars with hooks, captions, and CTAs.
- `avatar-video-pipeline` - Plan avatar/faceless video production from idea to script and publishing checklist.
- `launch-kit-executor` - Turn imported launch kits into execution plans and first tasks.
- `workflow-qa-checker` - Review automations for missing steps, risks, credentials, and test cases.

## Notes

These are local Angelic OS skills, not raw bulk imports from public marketplaces. External marketplace instructions should still be reviewed with `workflow-template-installer` or `workflow-qa-checker` before being trusted.
